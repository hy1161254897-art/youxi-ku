# 游戏库

**贺义制作，纯属娱乐。** 两款可以直接在浏览器打开的原创休闲游戏，支持电脑、手机与平板。

在线游玩：<https://hy1161254897-art.github.io/youxi-ku/>

## 游戏

| 游戏 | 内容 | 手机操作 |
| --- | --- | --- |
| 小贺茶馆 · 四川麻将 | 定缺、血战到底，三位电脑牌友，三档难度，原创新国风音乐 | 点选手牌，再点一次出牌；可用操作区按钮碰、杠、胡 |
| 小贺渔场 | 17 种海洋生物、独立肢体游动、炮击与捕获音效、鱼潮、技能 | 按住水面瞄准连发；可开启自动开火与锁定追踪 |

从首页选择游戏即可开始，不需要账号或下载应用。竖屏可玩，横屏能看到更宽阔的牌桌和海域；浏览器首次交互后才能播放声音。

两款游戏均为**单机游戏**，可以把链接分享给朋友各自游玩，暂不支持多人联机。金币、余额与进度分别保存在当前浏览器中，不会同步到其他设备。所有金额都是免费虚拟娱乐积分，没有真实支付或提现。

## 本地预览与验证

需要 Node.js 18 或以上版本；没有需要安装的第三方依赖。

```sh
npm start       # http://127.0.0.1:4175
npm test        # 两款规则引擎、捕鱼动画和网站路径测试
npm run build   # 将网页运行文件复制到 dist/
```

也可以直接打开 `index.html`，保持整个目录完整。

## GitHub Pages

仓库的英文地址名为 `youxi-ku`，中文网站名为“游戏库”。所有网页引用均为相对路径，适用于 GitHub Pages 项目站点。

仓库上传后，在 **Settings → Pages → Deploy from a branch** 选择 `main` 分支、`/ (root)`，保存即可发布。根目录的 `.nojekyll` 保持原生静态文件不经 Jekyll 转换。

# 小贺茶馆 · 四川麻将单机版

一款可离线游玩的四川麻将小游戏。小贺茶馆的青绿色牌桌，配有大字号界面、川渝经典牌面和三位原创人物头像。右上角水印为“贺义制作，仅供娱乐”。内置轻柔国风背景音乐，可离线循环播放。

## 启动游戏

从游戏库首页选择 **小贺茶馆**，即可在网页中开始对局，无需安装或注册。此目录是游戏库内的麻将源码，网页入口为 `games/mahjong/index.html`，页眉 **‹ 游戏库** 可返回两款游戏的首页。

支持现代手机 Safari、Chrome、Edge 等浏览器。手机竖屏使用两排大牌；特别窄的屏幕使用三排，避免挤成难以点击的小牌。横屏宽度达到 700 像素时，界面以牌桌为主，便于完整查看手牌和操作按钮。手机浏览器显示网址栏时，可以轻扫页面查看其余内容。

直接打开本目录的 `index.html` 也可以离线游玩，移动文件时请保留同目录的 CSS 和 JavaScript 文件。通过网站打开与文件直开可能分别保存设置及余额；推荐固定使用同一个入口。

## 操作与设置

- 你与张燕子、贺老五、贺小满三位电脑牌友同桌。张燕子是温柔端庄的老板娘，贺老五是爽朗随性的老板，贺小满是阳光帅气、不戴眼镜的大学生形象。人物名字下方不显示身份介绍。右侧可选择**简单、一般、困难**三档难度及 **￥10 / ￥20 / ￥50 / ￥100** 底分，修改后在下一局生效。人机依据自己的手牌和公开牌面决策。
- 开局选择定缺花色；轮到你时，**点击一张牌选中，再点一次出牌**，也可点击“出牌”按钮或按空格。左右方向键选牌，`H` 键或“出牌提示”按钮给出建议。轮到你时没有思考时间限制。
- 手机上轻触选牌，再次轻触该牌或点右下角 **出牌** 确认；选中的牌会抬起并显示名称。出牌、碰杠胡及常用操作使用至少 44 像素的触摸高度，页面保留双指缩放。横屏隐藏侧栏时，右上角设置仍可调整难度、底分、声音，以及查看战绩和管理余额。
- 可碰、杠、胡时，操作区会出现相应按钮；不接牌点击“过”。你胡牌后，其余牌友继续对局，可点击“快速看完”加快剩余进程。
- 人机默认按**每人 1 秒**的节奏依次操作。右上角音乐按钮可开关背景音乐；齿轮“游戏设置”内可调音量、操作音效、加大字号及对局速度（悠闲 1.6 秒/人 / 标准 1 秒/人 / 轻快 0.5 秒/人）。浏览器通常需要首次点击后才能播放声音。
- “玩法说明”“我的战绩”“管理余额”等弹窗打开时暂停牌局，关闭后继续；切到其他浏览器标签页时也暂停电脑操作。
- 牌桌右上角的重新开局按钮可提前结束本局。确认后保留已发生的得失，记录为“提前结束”，并使用当前选择的难度与底分开始新局。

## 虚拟余额与自动保存

初始余额为 **￥10,000**。胡牌、杠牌和流局结算发生时，钱包实时增加或扣除虚拟金额；完整对局结束后展示四家结算。余额可以因输牌变为负数，不影响继续游玩。

点击右侧钱包的 **管理余额**，可输入 **￥0 至 ￥1,000,000,000** 的金额（最多两位小数），使用快捷金额，或重置为 **￥10,000**。调整余额立即生效，后续牌局得失从新余额继续计算；不会清除历史战绩，也不会计入累计净收益。

余额、设置、最近 30 局战绩和未完成牌局保存在当前浏览器的本地存储中。正常保存后刷新或重新打开游戏会自动续局；完成的牌局不会重复计入收益。不同浏览器、不同文件路径，以及文件直开 / 本地网址可能使用不同存储。清除浏览器数据会清除这些记录；浏览器禁用本地存储时仍可玩本次对局，但无法保存。

所有金额均为本机娱乐积分，不涉及充值、提现或真实交易。

## 本作规则

采用四川麻将的“定缺 · 血战到底”休闲规则：使用万、筒、条三门共 108 张牌，开局定缺，不换三张；可以碰、明杠、暗杠、补杠，不能吃。本作持有定缺牌时只可优先打出缺门牌，清空后才可碰、杠、胡，不能碰杠缺门。支持一炮多响与抢杠胡。胡牌后的玩家退出本局，其余玩家继续，三家胡牌或牌墙摸尽时结束。

胡牌金额为 **底分 × 2 的番数次方**，番型可以叠加，最高 5 番（底分 × 32）：

| 番型 | 番数 |
| --- | --- |
| 平胡 | 0 番 |
| 对对胡、金钩钓 | 各加 1 番 |
| 七对、清一色 | 各加 2 番 |
| 每一根、自摸、杠上花、抢杠胡 | 各加 1 番 |

“根”指手牌与副露中合计四张相同牌。自摸由其余尚未胡牌的玩家分别支付；点炮或抢杠由出牌者向各胡牌者支付。明杠由放杠者付底分 × 2；暗杠由其余未胡玩家各付底分 × 2；补杠各付底分 × 1，若被抢杠胡则取消补杠。

牌墙摸尽时查花猪、查大叫并退税：未打完定缺的花猪向每位非花猪玩家付底分 × 16；尚未胡牌且非花猪的玩家中，未听牌者向已听牌者赔付其最高可胡分；未胡且未听牌或花猪的玩家退还已经收到的杠分。

各地区四川麻将的番型及结算方式有所不同，本作提供统一的休闲规则，并不覆盖所有地方规则。

## 开发与参考

本作使用原生 HTML、CSS、JavaScript；背景音乐和操作音效通过浏览器 Web Audio 合成，内置原创轻柔国风旋律，不依赖远程音频。界面、SVG 牌面、人物头像和游戏实现均为原创，没有复制以下项目的代码或素材。

开发时参考了以下公开项目的思路与功能方向：

- [kobalab/Majiang](https://github.com/kobalab/Majiang)：HTML5 麻将项目架构参考（该项目使用 MIT 许可）。
- [babykylin/babykylin_scmj](https://github.com/babykylin/babykylin_scmj)：四川麻将功能参考。
- [luxinghong/sichuan-mahjong-analyzer](https://github.com/luxinghong/sichuan-mahjong-analyzer)：规则及牌型分析参考。

如需执行规则引擎测试：

```powershell
node --test engine.test.js
```

测试使用 Node.js 内置模块，无需安装依赖。游戏库直接发布 HTML、CSS 和 JavaScript 源文件；修改后按仓库首页说明预览与发布。`mobile.css` 单独维护手机布局，不改变规则引擎。

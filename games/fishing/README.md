# 小贺渔场

**贺义制作，纯属娱乐。** 游戏库中的原创单机街机捕鱼游戏，支持电脑与手机浏览器。

## 开始游玩

从游戏库首页选择“小贺渔场”，或直接打开网站的 `games/fishing/` 页面，点击“开始捕鱼”即可。网站素材全部由同一静态站点提供，无账号、支付或服务器玩法依赖。

手机竖屏和横屏均可玩，横屏视野更开阔；手指滑动瞄准，按住连发。金币、免费补给和概率设置位于渔场顶部，无需向下翻找。右上角的全屏按钮支持原生全屏；浏览器不提供该能力时自动改用页内沉浸模式，再点一次退出。点击左上角返回游戏库。

首次点击后浏览器才允许播放声音；在右上角可以开关音乐，设置中可单独调节背景音乐与操作音效。推荐新版 Safari、Chrome 或 Edge。游戏可在不支持 WebGL 的浏览器中使用 Canvas 兼容动画；手机使用较小的动作缓存节省内存。

## 已有功能

- 原创海底美术，珊瑚秘境、月光深海、鎏金海湾三个海域配色；17 种海洋伙伴，包括苍穹帝王鲸、黄金鲨王、赤金龙虾、紫晶章鱼王、星海魔鬼鱼、翡翠海马、鎏金帝王蟹与深海龙皇。
- 鼠标 / 触屏瞄准，按住连发，自动开炮，目标锁定与追踪，反弹炮弹和范围渔网。
- 金甲、宝石与光泽甲壳的原创 3D 风格海兽美术；12 种大型与常见生物拥有按身体部位驱动的游泳动画：鱼尾与胸鳍、鲸尾、魔鬼鱼双翼、章鱼触腕、龙虾触须和步足、蟹钳、海马卷尾、海龟四鳍分别运动，头部和甲壳保持稳定。
- 每只动物拥有独立的动作节奏，平滑转向，随划水加速、滑行减速；冰冻同时减缓位移和身体动作，暂停时完全停止。首次载入会短暂准备动作缓存，之后可流畅绘制同种鱼群。
- 七档炮值：10、20、50、100、200、500、1,000。重型金属能量炮弹、旋转充能环、火焰尾流、炮口爆焰与后坐力；命中时爆破闪光、电弧与双层冲击波，再展开捕获渔网。
- 普通、珍稀、史诗、传说四级捕获反馈。黄金鲨王与深海龙皇具有更强的烟花、震屏、庆祝横幅、胜利乐句与金币音效。
- 原创 112 BPM、16 小节循环热带风 BGM，马林巴、钢鼓、低音和海岛鼓点；分层炮击、命中、技能及捕获操作音效，完全由 Web Audio 本地合成。
- 免费冰冻（减缓鱼群，持续 7 秒 / 冷却 32 秒）与狂暴（提高射速、扩大渔网，持续 9 秒 / 冷却 40 秒）。冷却从释放时起算。
- 每 45 秒鱼潮、每 75 秒深海龙皇巡游；连续 3.3 秒内捕获可以延续连捕。
- 免费自定义充值、捕捉概率调节、鱼类图鉴、累计战绩、航海成就、本地自动保存、暂停、全屏和手机布局。

## 金币、奖励与概率

首次进入获得 **20,000 游戏币**。每次实际发射扣除当前炮值，余额不足时自动停止开火并提示补给。捕获奖励为 **发射时炮值 × 鱼种奖励倍率**，倍率见图鉴。

点击“充值游戏币”可免费添加 1 至 1,000,000,000 之间的任意整数，也提供快捷数量。余额上限为 999,999,999,999。充值不计入捕鱼净收益。所有游戏币都是本机娱乐积分，不收取费用，不提供真实支付、交易或提现。

“好运加成”可选：

- **原版**：使用本作图鉴列出的基础概率。
- **提升 1–10 倍**：基础概率 ×（1 + 提升倍数），最高为 100%。例如基础概率 20%，提升 1 倍后为 40%，提升 4 倍后为 100%。
- **必中**：被炮弹或其渔网覆盖命中的鱼，捕获成功率为 100%。未命中鱼群的炮弹仍消耗金币。

炮值只改变单发成本与奖励，不改变基础概率。一个渔网内的每条鱼独立判定，每发炮弹对同一条鱼最多判定一次；设置修改对之后发射的炮弹生效。

## 操作

| 操作 | 功能 |
| --- | --- |
| 移动鼠标 / 手指 | 瞄准 |
| 点击 / 按住捕鱼区域 | 单发 / 连发 |
| 按住空格 | 连续开炮 |
| A | 自动开火开关 |
| L | 锁定追踪开关，默认选择高价值目标；点击鱼可切换 |
| F | 冰冻鱼群 |
| R | 狂暴速射 |
| P | 暂停 / 继续 |
| − / ＋ | 调整炮值 |

打开设置、充值、图鉴等弹窗，或切换到后台时暂停捕鱼与技能计时。暂停状态仍可操作设置与试听音效。若不喜欢震屏，可在设置中关闭“增强视觉反馈”。

## 保存与访问

金币、炮值、概率、音量、海域、鱼类收集、累计统计与最近捕获保存在当前浏览器本地；刷新后点击开始继续游玩。游动中的鱼、空中炮弹、临时技能效果与鱼潮倒计时会重新生成，不做逐帧续场。

不同浏览器、不同文件路径、文件直开与本地网址通常使用不同存档。清除浏览器数据会清除进度；浏览器拒绝本地存储时可以继续本次游玩，页面会给出提示。

## 开发与验证

原生 HTML / CSS / JavaScript、Canvas 2D、Web Audio，无第三方运行依赖。角色使用身体部位网格变形生成循环动画缓存，支持 WebGL 加速及 Canvas 兼容路径。安装 Node.js 18+ 后可在本文件夹执行：

```powershell
node --test engine.test.js animation.test.js
```

源码职责：`engine.js` 是游戏、运动与绘制引擎；`animation-rigs.js` 定义各物种的关节位置与肢体动作；`creatures.js` 加载图集、生成动作缓存并绘制；`audio.js` 是原创合成音乐和音效；`app.js` 是界面、设置与存档；`style.css` 是响应式布局。

网站直接使用这些源码与图片，无需打包。测试覆盖捕获与金币规则、运动和肢体动画、多指输入、指针丢失后停止射击、旋转屏幕后保持比例和游动位置。

本作代码、鱼类绘制、界面与音乐均为原创实现，未复制上述项目代码、商业游戏画面或音频。专属海底背景与海兽图集通过内置 image_gen 生成；用户提供的截图用于风格参考，没有直接使用其中的角色图像。背景为 `assets/ocean-reef.jpg`，角色图集为 `assets/creatures-a.png`、`creatures-b.png` 和 `creatures-c.png`。
